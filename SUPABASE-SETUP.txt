R&G FORGE 3D — MODO SUPABASE-ONLY

1. No Supabase, execute o arquivo supabase-setup.sql no SQL Editor.
2. Confirme que Authentication > Users contém o usuário administrativo configurado (ray@rgforge3d.local).
3. A aplicação carrega e salva dados comerciais somente na tabela public.app_data, sob a conta autenticada. O adaptador de compatibilidade mantém os dados em memória durante a página; ele NÃO lê nem grava registros comerciais em localStorage/sessionStorage.
4. IMPORTANTE: dados que existiam apenas no navegador anterior não serão importados automaticamente. Antes da troca, exporte os backups e planeje uma importação explícita; este pacote não lê o armazenamento local antigo.
5. A sessão de autenticação é gerenciada pelo SDK do Supabase para permitir navegação entre páginas. Isso é credencial de sessão, não armazenamento de pedidos/estoque/financeiro.
6. Realtime é usado para atualizar páginas abertas quando o projeto Supabase tiver a tabela app_data habilitada na publicação Realtime. Sem isso, cada página ainda carrega os dados mais recentes do banco ao abrir/recarregar.
7. Se a gravação falhar, a interface mostra aviso vermelho; os dados não são tratados como salvos com sucesso. Confira RLS, SQL e a conexão.

A chave publishable pode estar no frontend; NUNCA coloque service_role/secret key no site.
